# کارت مقابله‌ای طرح‌واره (Schema Coping Card) - نسخه ۰.۲

برنامه تحت وب و آفلاین برای ثبت، مدیریت و بازخوانی کارت‌های مقابله‌ای بر اساس **طرح‌واره‌درمانی جفری یانگ (Jeffrey Young)**.

## ویژگی‌ها:
- **۱۰ گام استاندارد در ۴ بخش درمانی:**
  1. پذیرش احساس فعلی (هیجان‌ها و موقعیت برانگیزاننده)
  2. طرح‌واره‌ها (انتخاب از میان ۱۸ طرح‌واره فعال، ریشه در کودکی، تحریف‌های شناختی)
  3. واقعیت‌آزمایی (تفکر منفی، دیدگاه سالم و شواهد تأییدکننده)
  4. دستور رفتاری (رفتار تکانشی و رفتار سالم جانشین)
- **کارکرد ۱۰۰٪ آفلاین:** به عنوان یک Progressive Web App (PWA) پس از اولین اجرا، بدون نیاز به اینترنت کار می‌کند.
- **آرشیو داخلی هوشمند:** ذخیره‌سازی نامحدود کارت‌ها روی حافظه دستگاه با امکان جستجو، خواندن، اشتراک‌گذاری، خروجی متنی، انتخاب هم‌زمان و پشتیبان‌گیری.
- **سازگاری کامل با آیفون (iOS) و اندروید:** طراحی شده با استانداردهای مدرن وب و بدون نیاز به نصب هیچ فایل یا برنامه جانبی.

## نحوه استفاده و نصب روی گوشی:
1. لینک برنامه را در مرورگر گوشی (سافاری در آیفون / کروم در اندروید) باز کنید.
2. گزینه **Add to Home Screen (افزودن به صفحه اصلی)** را انتخاب کنید تا آیکون برنامه روی صفحه گوشی شما قرار گیرد.
